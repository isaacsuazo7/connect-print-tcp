== INSTALACION (o actualizacion) ==

- Copiar el YaloPrinterService.exe compilado (npm run build && npm run packing -> dist) en la carpeta "resources".
- Doble click en "install". Pide permisos de administrador.
- Si habia una version anterior instalada, la reemplaza.
- El servicio queda escuchando en el puerto 3000 de TODAS las redes de la PC y en 127.0.0.1.
  El POS de esta PC lo encuentra solo: ya no hace falta copiar la IP en el POS ni en el flag de Chrome.
- Arranca solo al prender la PC (con retardo, para esperar la red) y se reinicia solo si se cae.
- Queda en %ProgramFiles%\Yalo\PrintAgent. La carpeta del paquete se puede borrar despues de instalar.
- Logs y datos (cola, impresoras): %ProgramData%\Yalo\PrintAgent (servicio.log)

== ACTUALIZACIONES ==
- Se actualiza solo cuando Yalo publica una version nueva: la baja, verifica la firma y la aplica
  cuando no hay nada imprimiendose. Si la nueva no arranca en 60 s, vuelve sola a la anterior.
- Instalar este paquete a mano siempre manda: borra las versiones bajadas y arranca con la del paquete.

== VER SI RESPONDE ==
- Abrir en el navegador: http://127.0.0.1:3000/health

== REINICIAR SERVICIO ==
- Carpeta "extra" -> doble click en "restart".

== VER LAS IP DE ESTA PC ==
- Solo hace falta si una tablet imprime A TRAVES de esta PC desde el navegador.
- Carpeta "extra" -> doble click en "showHostname".

== ELIMINAR SERVICIO ==
- Carpeta "extra" -> doble click en "uninstall".
- En la ventana "Remove the service?" elegir "Yes".
